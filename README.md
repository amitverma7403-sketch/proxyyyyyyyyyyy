# NodeMax

Mobile proxy nodes. Each Android phone connects to your own server and becomes an exit IP.

## Download

Latest APK: https://github.com/amitverma7403-sketch/proxyyyyyyyyyyy/releases/latest

Install `NodeMax.apk`, open it, and scan the QR code from your NodeMax dashboard.
No login is needed to download.

## Security

- HTTPS only; user-installed certificates are not trusted by the app.
- Release builds are signed with one fixed key. Check with `apksigner verify --print-certs NodeMax.apk`.
- No backups of app data, no exported components apart from the launcher and pairing link.
- Report problems privately to the repository owner.
